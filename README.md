# Airlines Ticket Price & Route Analytics

> An end-to-end data analytics project that analyzes over **300,000 airline booking records** to uncover pricing trends, customer booking behavior, route demand, and airline performance using **Python, SQL, and Data Visualization**.

---

# Executive Summary

Airline ticket pricing depends on multiple factors including airline, travel class, booking lead time, flight duration, number of stops, and route popularity.

This project performs a complete data analytics workflow to transform raw airline booking data into meaningful business insights that support pricing optimization, demand forecasting, and operational decision-making.

---

# Business Problem

Airlines need to understand how different operational factors influence ticket prices and passenger demand.

The objective of this project is to identify:

- Pricing trends across airlines
- Impact of booking lead time
- Route popularity
- Customer travel behavior
- Revenue opportunities
- Flight demand patterns

---

# Project Objectives

- Clean and prepare airline booking data
- Perform exploratory data analysis (EDA)
- Analyze ticket pricing trends
- Compare airline and travel class performance
- Study booking behavior
- Identify busiest routes and cities
- Answer business questions using SQL
- Generate actionable business recommendations

# SQL Analysis

Solved 17 business-focused analytical problems including:

- Average ticket prices by airline
- List the top 5 most expensive routes (source to destination)
- Which airline offers the lowest average ticket price for Business class?
- Find routes with more than 50 flights and their average ticket prices
- Compare average price difference between Economy and Business class per airline
- Which cities have the most incoming flights?
- Which cities have the most outgoing flights?
- Busiest route (most number of flights)
- Top 3 airlines with cheapest average prices for each route
- Flights with duration more than 5 hours but priced below average
- Which flight class shows the highest average price variation (std deviation)?
- Find how ticket prices vary with number of days left before departure
- Which time of day (Morning, Evening, etc.) has the highest average ticket price?
- Find Price trends by airline and travel class
- Compare the airlines average prices for non-stop vs. 1-stop vs. 2+ stops flights
- Booking Window Analysis
